Crosswind Calculator

Enter a runway and the wind to get the headwind, tailwind and crosswind components for both runway directions.

Input

01–36, optionally with L / C / R. The reciprocal runway is worked out automatically.

Picture

Components

Simplified: the runway heading is taken as designator × 10° and the wind is assumed to be in the same reference (magnetic vs. true is not corrected). Gust components are calculated with the full gust value. For illustration only, not for operational use.
